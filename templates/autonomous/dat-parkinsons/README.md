# DaT Parkinson's Challenge — Autonomous demo

This is a safe, synthetic starter campaign for Joe. It mirrors the public
interface of DrivenData's challenge, but contains no challenge data and submits
nothing. Restricted data must never be uploaded to an AI provider; Joe may
receive only public documentation, aggregate metrics and sanitized error logs.

Run `python experiment.py`; it writes `metrics.json` for the Autonomous loop.
